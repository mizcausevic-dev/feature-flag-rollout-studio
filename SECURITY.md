# Security Policy

This repository is a portfolio project and does not operate real release controls or production feature flags.

## Reporting

If you identify a security issue in the development workflow or project shell, please report it through GitHub Security Advisories or via the official contact routes on [Kinetic Gain](https://kineticgain.com/).

## Scope

- Demo data remains synthetic.
- No live credentials or rollout keys should be committed.
- Package hygiene should continue through Dependabot and CI.
